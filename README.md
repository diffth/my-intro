# 홍길동 · 자기소개 프로필

미니멀하고 세련된 글래스모피즘 디자인과 감각적인 마이크로 인터랙션이 적용된 개인 소개 웹 페이지입니다.

## ✨ 주요 기능
- **🌌 배경 부유 파티클**: 30개의 스카이블루 점들이 은은한 투명도와 함께 부드럽게 떠다니는 배경 애니메이션
- **💫 카드 호버 Stagger 인터랙션**: 프로필 카드에 마우스를 올리면 관심 태그가 좌측부터 순차적으로 통통 튀며 떠오르는 모션
- **🏷️ 개별 태그 하이라이트**: 태그 호버 시 스카이블루 액센트 컬러 및 입체적인 섀도우 효과
- **📱 반응형 디자인**: 모바일과 데스크톱 화면 모두 최적화된 레이아웃
- **♿ 접근성 지원**: `prefers-reduced-motion` 설정을 감지하여 모션 감소 모드 완벽 지원

## 💻 로컬 실행 방법
```bash
# Python 내장 서버로 실행
python -m http.server 3000
```
웹 브라우저에서 `http://localhost:3000`으로 접속합니다.
