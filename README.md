# 홍길동 · 자기소개 프로필

미니멀하고 세련된 글래스모피즘 디자인의 개인 소개 웹 페이지입니다.

## 🚀 주요 기능
- **반응형 디자인**: 모바일과 데스크톱 화면 모두 최적화된 레이아웃
- **글래스모피즘 카드**: 반투명 배경과 부드러운 블러 효과의 프로필 카드
- **소셜 링크**: GitHub, LinkedIn 바로가기

## 💻 로컬 실행 방법
```bash
# Python 내장 서버로 실행
python -m http.server 3000
```
웹 브라우저에서 `http://localhost:3000`으로 접속합니다.
